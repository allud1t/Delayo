## 1.3.0 (2026-08-21)

### Features

- add editable time fields, quick presets, and month/year calendar navigation
- add General, Statistics, and About sections to the settings view
- add local productivity statistics and English, Portuguese, and Spanish translations

### Fixes

- use the packaged extension icon for scheduled notifications
- align recurring scheduling controls and improve release packaging for the Chrome Web Store
